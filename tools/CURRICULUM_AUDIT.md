# 按两张课程图验收 MiniQuant

读者是有 AI 算法经验、没有量化经验的工程师。验收目标不是堆模型名，而是能把**点时数据 → 采样 → 特征 → 标签 → 验证 → 信号 → 组合 → 订单 → 成交 → 风控/复盘**逐步讲清并跑通。第三张图片中的业绩与“首次公开”字样是未经本项目核验的宣传主张，不是课程要求。

标记：**实作**＝ Notebook 可运行并有输出；**讲解**＝有定义、适用边界和反例，但未假装机构级数据；**待接入**＝缺少真实授权行情或券商环境。

| 图片知识点 | MiniQuant 落点 | 状态与章节验收 |
|---|---|---|
| 1 机器学习基础/类别/场景 | 开篇路线；Ridge、Logistic、GBDT 简短对比 | 讲解。AI 工程师可跳读；能说明为何低训练损失不等于交易收益 |
| 2 金融数据来源、国内外差异 | 真实行情来源/manifest；A 股 Level-2 数据合同 | 实作+讲解。能说清当前真实美股日线与教学 A 股盘口夹具的差别 |
| 2 差分、厚尾、金融时间轴问题 | 探索/统计与“重尾、异方差”小实验 | 实作。能区分价格差分、收益、时间采样和事件采样 |
| 3 非时间轴、Dollar Bar | 第二篇“非时间轴”；教学逐笔 Dollar Bar | 实作（教学夹具）。能逐笔核算 Bar 结束点，知道阈值只由训练期决定 |
| 3 “C₁ 自定义轴” | 第二篇自定义轴说明 | **未复现**：图片没有定义式或代码，不能擅自声称复现；取得原课程公式后可接入同一轴接口 |
| 3 一阶差分“接近正态” | 真实日收益的偏度/峰度/尾部检验 | 实作反证。绝不保证差分或 Dollar Bar 必然更接近正态 |
| 4 趋势、事件标签、标签密度 | “标签工程”固定期三分类、路径型屏障的边界 | 实作+讲解。能说出标签期限、类别阈值、重叠与密度的影响；完整 triple-barrier/trend-scanning 留作扩展 |
| 4 标签与特征、训练关系 | 决策时间线、purge 交叠演示 | 实作。能查出标签可以看未来、特征不能看未来 |
| 5 金融/数学特征、非时间轴窗口、熵 | 成交额变化因子、Dollar Bar 收益/历时/方向熵 | 实作。能先讲机制，再讲变换；同时报告 Bar 数和实际历时 |
| 6 降维方法、实时推理 | 训练期 PCA+Ridge、实时 schema 合同 | 实作+讲解。能说明 PCA 后上线仍需要完整原始特征 |
| 7 模型训练、传统/神经、比较、过拟合 | Ridge/Logistic/GBDT；红队；成本敏感性 | 实作+讲解。以样本外 IC、成本、容量而非训练损失验收 |
| 8 数据驱动/逻辑驱动、跨资产 | 因子机制与模型；ETF/期货迁移清单 | 讲解。能列出股票与 ETF/期货标签、交易规则不能直接共用的原因 |
| 9 组合模型与不同轴融合 | 固定权重排名融合，跨轴时间对齐要求 | 实作+讲解。能测试组合是否真的比单模型增加信息 |
| 10 实时推理、自动成交、资金容量 | 部分成交/VWAP 教学撮合、容量数量级、在线故障回退 | 实作+讲解；真实券商自动下单**待接入**，不对教学环境发单 |
| 11 阅读 | Notebook 末尾的原始论文、官方文档和本地来源 | 讲解。先读交易所字段和原始研究，再扩展方法 |

## 按章节交作业

1. **市场与数据**：解释买卖一、限价单、价差与滑点；指出当前快照的幸存者偏差；给出数据唯一键、复权和点时可得性检查。
2. **采样、特征与标签**：手算一根 Dollar Bar；画出特征可得时间与标签完成时间；解释为何相邻 5 日标签不能随机分行验证；给出金融机制和失败反例。
3. **模型与降维**：复现 Ridge/GBDT/PCA 基线；每个预处理器只在训练期拟合；报告 IC、分组、类别比例、训练/测试日期和所有调参记录。
4. **策略与执行**：从分数形成权重，计算首次建仓、漂移、换手和成本；手算 10,000 股申请与 8,000 股成交的持仓差；做资金规模与容量敏感性。
5. **实习作品**：因子岗交字段合同和因子检验；模型岗交样本外基线/消融；策略岗交订单状态机、风控和净值复盘。三岗都要附失败案例与复现实验。

## 未伪装成已完成的部分

- 没有经授权的真实 A 股逐笔/十档文件，所以 Dollar Bar 和订单撮合只用明确标记的教学夹具。机构级重建需要交易所版本、通道序号、快照校准与权限合同。
- 没有券商或仿真交易接口，所以没有“全自动实盘交易”代码。教学撮合只说明价量与部分成交，不验证真实队列位置或网络延迟。
- 图三的 Calmar 超 3、资金管理规模提升、首次公开等说法没有可审计数据和独立样本外报告；教材只介绍 Calmar 定义、计算与过拟合风险。
- ETF、股指和商品期货的细则在本版是迁移清单；不把美股日线或 A 股股票成本模型直接外推到这些资产。
